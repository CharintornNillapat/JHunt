## Goal
Stop the Turso database URL from appearing in the public Actions logs, and fix the small problems the Task 0.2 review found in `get_storage()` and its tests.

---

## Current behavior (evidence)

1. **URL leak (security).** [turso_client.py:66](../../src/storage/turso_client.py) logs
   `f"[TursoClient] Connected to Turso cloud database: {self.database_url}"` at INFO level.
   `main.py:43` sets `logging.basicConfig(level=logging.INFO)`, so this line prints on every CI run.
   `self.database_url` is the `https://` rewrite of the `libsql://` secret (turso_client.py:45-46), so GitHub's
   secret masking doesn't catch it. AGENTS.md: "Never log secrets, tokens, or database URLs".
2. **The URL can also leak through exception text.** turso_client.py:68-71 logs `({e})` when the connection fails.
   Network errors from libsql/aiohttp usually include the host (for example `Cannot connect to host <db>.turso.io:443`).
3. **Misleading log lines when Turso is required.** `src/storage/__init__.py:41` and `:44` log "Falling back to local SQLite."
   With `JHUNT_REQUIRE_TURSO=1`, the code raises `RuntimeError` right after those lines, so the CI log says it fell back when it didn't.
   Line 44 also logs `({e})` (same leak risk as item 2).
4. **Error message names the wrong cause.** The `RuntimeError` text says "JHUNT_REQUIRE_TURSO is set" even when the caller
   passed `require_cloud=True` (env var unset) or `force_sqlite=True`.
5. **Test writes to the repo.** `test_get_storage_require_cloud_falsy_env_var_falls_back` (tests/test_storage.py:882-887)
   calls `get_storage()` with no `db_path`, so it opens `data/market.db` six times and never closes the connections.

## Changes

### 1. `src/storage/turso_client.py`
- Add `from urllib.parse import urlparse` (stdlib).
- Add a private method:
  ```python
  def _redact(self, text: object) -> str:
      """Removes the database URL and its hostname from text that is about to be logged."""
      out = str(text)
      host = urlparse(self.database_url).hostname if self.database_url else None
      for secret in (self.database_url, host):
          if secret:
              out = out.replace(secret, "<turso-db>")
      return out
  ```
- Line 66: `logger.info("[TursoClient] Connected to Turso cloud database.")` (no URL).
- Lines 68-71: log `self._redact(e)` instead of `e`.

### 2. `src/storage/__init__.py`
- Line 41: `logger.info("[Storage] Turso client unavailable.")`
- Line 44: `logger.warning(f"[Storage] Failed to initialize Turso client ({type(e).__name__}).")` (exception type only, no message text).
- Right before `return DatabaseManager(db_path=db_path)`: `logger.info("[Storage] Falling back to local SQLite.")`.
  The fallback is logged only when it actually happens. This also covers the no-credentials case, which logs nothing today
  (`TursoClient` itself is never constructed there).
- `RuntimeError` message:
  `"Turso is required (require_cloud=True or JHUNT_REQUIRE_TURSO) but unavailable; refusing to fall back to local SQLite."`
