## Goal
Restore real-time pipeline log observability in GitHub Actions CI and prevent output truncation upon process termination by configuring `PYTHONUNBUFFERED: "1"` in the workflow environment and defensively flushing standard output streams prior to `os._exit()`.

---

## Current Behavior (Evidence)
1. **Block Buffering in GitHub Actions Runner:**  
   In `.github/workflows/scraper_cron.yml:70-80`, the `Run JHunt pipeline` step executes `uv run python main.py run --all --limit 30` without setting `PYTHONUNBUFFERED`. In a non-interactive CI runner environment where stdout is piped, Python defaults to 4KB/8KB block buffering for `sys.stdout`.
2. **Abrupt Process Termination Bypasses Buffer Flush:**  
   In `main.py:456-459`, `main.py` invokes `os._exit(exit_code)` to prevent background thread / connection leaks from hanging the runner. Because `os._exit` bypasses standard Python exit handlers (`atexit` and stdio buffer flushing), any buffered `print()` messages (pipeline progress, scraper counts, market reports) that have not crossed the buffer threshold are dropped if an unhandled crash or early termination occurs.

---

## Changes

### 1. `.github/workflows/scraper_cron.yml`
- In step `Run JHunt pipeline` (around line 70), add `PYTHONUNBUFFERED: "1"` under `env:`:
  ```yaml
        - name: Run JHunt pipeline
          env:
            PYTHONUNBUFFERED: "1"
            JHUNT_REQUIRE_TURSO: "1"
            TURSO_DATABASE_URL: ${{ secrets.TURSO_DATABASE_URL }}
            ...
  ```

### 2. `main.py`
- In the `finally:` block of `if __name__ == "__main__":` (lines 456-459), explicitly flush `sys.stdout` and `sys.stderr` before `logging.shutdown()` and `os._exit()`:
  ```python
      finally:
          try:
              sys.stdout.flush()
              sys.stderr.flush()
          except Exception:
              pass
          logging.shutdown()
          os._exit(exit_code if isinstance(exit_code, int) else 0)
  ```
  This ensures that even during local execution, container runs, or environments without `PYTHONUNBUFFERED=1`, buffered standard streams are flushed to the OS before `os._exit()` terminates the process.
