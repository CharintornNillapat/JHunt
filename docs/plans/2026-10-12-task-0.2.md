# Plan: Task 0.2 — Enforce Turso as Single Source of Truth in CI

**Date:** 2026-10-12  
**Task ID:** 0.2  
**Reference:** `docs/audits/2026-10-12-remediation-plan.md` (Task 0.2), `docs/audits/2026-10-12-architecture-reflection.md` (P0-1)

---

## Goal
Enforce Turso cloud storage as the non-negotiable Single Source of Truth in CI and production environments by making `get_storage()` raise `RuntimeError` when `require_cloud=True` or `JHUNT_REQUIRE_TURSO=1` and Turso is unavailable, eliminating silent ephemeral SQLite data loss.

---

## Disagreements / Alignment Notes
1. **Scope of Workflow Changes**: `docs/audits/2026-10-12-architecture-reflection.md` (line 187) bundled `PYTHONUNBUFFERED: "1"` together with `JHUNT_REQUIRE_TURSO: "1"` in one workflow diff. However, `docs/audits/2026-10-12-remediation-plan.md` explicitly isolates `PYTHONUNBUFFERED: "1"` into Task 0.3. Following the single-task-per-session rule, this task (0.2) only adds `JHUNT_REQUIRE_TURSO: "1"`.
2. **`TursoClient.init_schema` table batch wrapping**: `docs/audits/2026-10-12-architecture-reflection.md` (line 190) suggested wrapping table batch execution in `try/except`. However, table statements (`CREATE TABLE IF NOT EXISTS`) are foundational DDL. If table creation fails, succeeding queries will fail. Furthermore, Task 0.2 in the remediation plan specifically scopes to `get_storage()` raising on unavailable Turso. Modifying `TursoClient.init_schema` DDL resilience is deferred to Phase 1.

## Changes

### 1. `src/storage/__init__.py`
- Update function signature of `get_storage`:
  ```python
  def get_storage(
      database_url: Optional[str] = None,
      auth_token: Optional[str] = None,
      db_path: Optional[Union[str, Path]] = None,
      force_sqlite: bool = False,
      require_cloud: Optional[bool] = None,
  ) -> Union[TursoClient, DatabaseManager]:
  ```
- Add cloud requirement resolution with empty-is-unset semantics:
  ```python
  if require_cloud is None:
      require_cloud = (os.getenv("JHUNT_REQUIRE_TURSO") or "").strip().lower() in ("1", "true", "yes", "on")
  ```
- Before returning `DatabaseManager(db_path=db_path)` (when `force_sqlite` is True or Turso initialization fails or credentials are unset), guard with:
  ```python
  if require_cloud:
      raise RuntimeError(
          "JHUNT_REQUIRE_TURSO is set but Turso is unavailable; refusing to write to ephemeral local SQLite."
      )
  ```
- Invariant compliance:
  - Does NOT import `main` (uses `(os.getenv("JHUNT_REQUIRE_TURSO") or "").strip().lower() in (...)`).
  - Preserves local SQLite fallback for laptop use when `require_cloud=False` and `JHUNT_REQUIRE_TURSO` is unset.

### 2. `.github/workflows/scraper_cron.yml`
- Under step `Run JHunt pipeline` (around line 70), add `JHUNT_REQUIRE_TURSO: "1"` to `env:`:
  ```yaml
        - name: Run JHunt pipeline
          env:
            JHUNT_REQUIRE_TURSO: "1"
            TURSO_DATABASE_URL: ${{ secrets.TURSO_DATABASE_URL }}
            ...
  ```

## Tests to Add

In `tests/test_storage.py` (under `TestStorageFactory`):

1. `test_get_storage_require_cloud_explicit_raises_when_no_credentials`:
   - **Asserts**: `get_storage(require_cloud=True)` with no credentials in environment raises `RuntimeError` matching `"JHUNT_REQUIRE_TURSO is set but Turso is unavailable"`.
   - **Why it fails today**: `get_storage()` does not accept `require_cloud` argument (`TypeError: unexpected keyword argument`) and falls back to `DatabaseManager`.

2. `test_get_storage_require_cloud_env_var_raises_when_no_credentials`:
   - **Asserts**: With `JHUNT_REQUIRE_TURSO="1"` in `os.environ` and blank `TURSO_*` credentials, `get_storage()` raises `RuntimeError`.
   - **Why it fails today**: `get_storage()` ignores `JHUNT_REQUIRE_TURSO` and returns `DatabaseManager`.

3. `test_get_storage_require_cloud_env_var_truthy_variations`:
   - **Asserts**: Values `"true"`, `"yes"`, `"on"` for `JHUNT_REQUIRE_TURSO` also enforce `require_cloud` and raise `RuntimeError` when Turso is unavailable.
   - **Why it fails today**: Env var is ignored today.

4. `test_get_storage_require_cloud_falsy_env_var_falls_back`:
   - **Asserts**: With `JHUNT_REQUIRE_TURSO="0"` or `"false"` or `""` (unset/whitespace), `get_storage()` gracefully falls back to `DatabaseManager`.
   - **Why it fails today**: Tests that empty-means-unset invariant holds and does not falsely trigger `RuntimeError`.

5. `test_get_storage_require_cloud_force_sqlite_raises`:
   - **Asserts**: Calling `get_storage(force_sqlite=True, require_cloud=True)` raises `RuntimeError`.
   - **Why it fails today**: Keyword argument `require_cloud` unsupported today.

6. `test_get_storage_require_cloud_returns_turso_when_available`:
   - **Asserts**: With `require_cloud=True` and a mocked available `TursoClient`, `get_storage()` returns the `TursoClient` instance without raising.
   - **Why it fails today**: Keyword argument `require_cloud` unsupported today.
