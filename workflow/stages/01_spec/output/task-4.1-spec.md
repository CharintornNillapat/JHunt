**Reference:** `docs/contexts/task-ledger.md` (Phase 4), `AGENTS.md` (Definitions & Invariants), `anti-slop/audit-001-2026-10-10.md` (Finding 11: R-17/R-36/R-38), `antislop` Skill Suite (Mode 1 DURING)

## Goal
Implement end-to-end provenance tracking and honest source attribution across the pipeline and UI (schema, storage, generator, and web frontend), explicitly distinguishing whether an architecture blueprint was synthesized via live Gemini model reasoning (`provenance: "llm"`) or derived from a curated offline archetype (`provenance: "fallback"`), eliminating unbacked assertions of determinism and adhering strictly to antislop Mode 1 (DURING) and WCAG AA standards.

---

## Current Behavior (Evidence)

1. **Missing Schema Column (`src/storage/schema.py:8-19`)**:
   - `GENERATED_PROJECTS_DDL` creates `generated_projects` with columns: `id`, `title`, `role`, `difficulty`, `domain`, `tech_stack`, `spec_markdown`, and `created_at`.
   - There is no `provenance` or `source` column. The database cannot distinguish whether a stored spec came from Gemini or from offline fallback archetypes.

2. **Storage Methods Drop Provenance (`src/storage/db.py:525-543`, `src/storage/turso_client.py:516-554`)**:
   - `DatabaseManager.record_generated_project` and `TursoClient.sync_blueprint` hardcode the 6-parameter insert without accepting or persisting provenance.

3. **Generator Does Not Tag Provenance (`src/generator/markdown_exporter.py:180-205`)**:
   - `IdeationEngine` contains `IdeationEngine.is_fallback(spec)` (`ideation_engine.py:227`), but `MarkdownExporter.export()` does not save this distinction to the database record or include it in markdown frontmatter.

4. **Web UI Lacks Source Attribution (`web/src/lib/turso.ts:9-18`, `BlueprintCatalog.tsx`, `BlueprintReader.tsx`)**:
   - `GeneratedProject` interface in `web/src/lib/turso.ts` does not include `provenance`.
   - Neither `BlueprintCatalog` cards nor `BlueprintReader` HUD show readers where the spec originated, conflating LLM-generated specs with static offline archetypes.

### 2. Storage Layer Method Signatures
- **File**: `src/storage/db.py`
  - Update `record_generated_project`:
    ```python
    def record_generated_project(
        self,
        title: str,
        role: str,
        tech_stack: Union[List[str], str],
        difficulty: str = "",
        domain: str = "",
        spec_markdown: str = "",
        provenance: str = "llm",
    ) -> int:
        stack_str = json.dumps(tech_stack, ensure_ascii=False) if isinstance(tech_stack, list) else str(tech_stack)
        with self._connection() as conn:
            cursor = conn.execute(
                """
                INSERT INTO generated_projects (title, role, difficulty, domain, tech_stack, spec_markdown, provenance)
                VALUES (?, ?, ?, ?, ?, ?, ?);
                """,
                (title.strip(), role.strip(), difficulty.strip(), domain.strip(), stack_str, spec_markdown, provenance.strip()),
            )
            return cursor.lastrowid or 0
    ```
- **File**: `src/storage/turso_client.py`
  - Update `sync_blueprint`:
    ```python
    def sync_blueprint(
        self,
        title: str,
        role: str,
        difficulty: str = "Intermediate",
        domain: str = "",
        tech_stack: Union[List[str], str] = "",
        spec_markdown: str = "",
        provenance: str = "llm",
        **kwargs: Any,
    ) -> bool:
        ...
        self.client.execute(
            """
            INSERT INTO generated_projects (
                title, role, difficulty, domain, tech_stack, spec_markdown, provenance
            ) VALUES (?, ?, ?, ?, ?, ?, ?);
            """,
            [
                str(title).strip(),
                str(role).strip(),
                str(difficulty or "Intermediate").strip(),
                str(domain).strip(),
                stack_str,
                str(spec_markdown),
                str(provenance or "llm").strip(),
            ],
        )
    ```
